### What I do

I design and ship full-stack platforms end-to-end — product spec, database schema, payments, deployment — for real operating businesses, not portfolio filler. Most builds go from spec to production with me as the sole engineer, working through detailed phased build plans executed with AI coding agents (Claude Code, Cursor).

### Featured work

**🦁 Axelo Safari Suite** — full-stack safari booking platform for tour operators
`Next.js 14` `Supabase` `IntaSend (M-Pesa)` `Stripe` `Claude API`
Booking, payments, and ops in one system. Phase 9 in progress: an AI voice receptionist (Africa's Talking + Vapi.ai + Claude + ElevenLabs) that answers calls, books guests, and texts confirmations.

**🛡️ B2K Ops** — guard-force operations platform for a manned-guarding firm
`Next.js` `Supabase`
18-feature spec covering scheduling, patrols, and incident reporting, with a WiFi-CSI intrusion-sensing add-on in the pipeline. Live and demo-ready.

**⚙️ driftlock** — scope-control and governance tooling for AI coding agents
`CLI` `npm` — [driftlock-cli](#) · Driftlock Studio (autonomous AI web-build agent platform, launching Oct 2026)
Built because AI agents drift off-spec on long builds — driftlock keeps them honest. Published on npm, shipped commercially with tiered pricing.
